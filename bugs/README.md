# Bug Reports

Create one Markdown file per confirmed bug. Use a unique ID as the filename, for example `BUG-001.md`. Each report must include a bilingual title, environment, preconditions, reproduction steps, expected result, actual result, severity, evidence, related test case, and OWASP Top 10 (2021) reference.

# Relatórios de Bugs

Crie um arquivo Markdown por bug confirmado. Use um ID único como nome do arquivo, por exemplo `BUG-001.md`. Cada relatório deve incluir título bilíngue, ambiente, pré-condições, passos para reprodução, resultado esperado, resultado obtido, severidade, evidência, caso de teste relacionado e referência OWASP Top 10 (2021).
